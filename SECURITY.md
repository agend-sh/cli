# Reporting security issues

Report suspected security vulnerabilities in the Agend CLI, MCP bridge, or
hosted service privately to [hello@agend.sh](mailto:hello@agend.sh).

Include the affected version, a description of the issue, and reproduction
steps if available. Omit account tokens, passwords, and customer data.

For ordinary bugs and feature requests, use the
[GitHub issue tracker](https://github.com/agend-sh/cli/issues).
